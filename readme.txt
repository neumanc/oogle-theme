Oogle's reusable block theme foundation. Neutral by design; client sites are child themes.

== Description ==

A lightweight, standards-based WordPress block theme intended as a parent for client sites.
theme.json token contract, thin templates, core-block patterns, per-block CSS, two optional
progressive-enhancement script modules, no build step, no jQuery, no framework. Updates are
delivered from GitHub Releases through WordPress's own update mechanism. See README.md.
