Oogle's reusable block theme foundation. Neutral by design; client sites are child themes.

== Description ==

A lightweight, standards-based WordPress block theme intended as a parent for client sites.
theme.json token contract, thin templates, core-block patterns, per-block CSS, no build step,
no JavaScript of its own. See README.md and docs/.
